# Features

Standalone, full-screen Gecko-powered ChatGPT app for iOS 16 and earlier.

- Right-edge swipe to refresh with a native animation, and left-edge swipe to go back.
  
- Wider sidebar, refined header icons, stable Share button and chat-header appearance.
  
- ChatGPT Appearance shortcut in Settings, plus browsing-history and selective app-data controls.
  
- Download handling, external links and microphone permissions.
